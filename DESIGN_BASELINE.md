## Ключевые характеристики стиля

- **Общий стиль**: Apple/iOS-подобный (San Francisco системный шрифт через `-apple-system`, скругления, лёгкие тени, blur-подложки).
- **Верстка**: одна колонка, максимальная ширина контента 600px, мобильный форм-фактор в приоритете.
- **Шапка**: sticky-хедер с `backdrop-filter: blur(20px) saturate(180%)`, логотип-иконка машины + текст "ДКП", кнопка переключения темы (эмодзи 🌙/☀️) справа.
- **Табы шагов**: 4 шага ("Загрузка" → "Распознавание" → "Проверка" → "Договор") в виде pill-переключателя на светлой подложке `--card-2`, активный таб — белая/тёмная карточка с тенью.
- **Карточки**: `border-radius: 20px` (`--radius-lg`), тонкая рамка `--border` (полупрозрачная), мягкая тень `--shadow`, фон `--card`.
- **Цветовая палитра** (системная iOS):
  - `--blue: #007aff` — основной акцент (кнопки, активные элементы)
  - `--green: #34c759` — успех/совпадение данных
  - `--orange: #ff9500` — предупреждение
  - `--red: #ff3b30` — конфликт/ошибка
  - Светлая тема: фон `#f2f2f7`, карточки `#ffffff`
  - Тёмная тема: фон `#000000`, карточки `#1c1c1e` (авто через `prefers-color-scheme` + ручной тоггл через `data-theme`)
- **Зоны загрузки файлов**: пунктирная рамка, иконка-эмодзи слева, название и статус ("Ждём"/"Загружен") справа в виде pill-бейджа.
- **Поля форм**: `border-radius: 10px`, фон `--card-2`, синяя рамка при фокусе (`--blue`), цветная рамка при конфликте/предупреждении/ок (красная/оранжевая/зелёная).
- **Нижняя панель действий**: закреплена внизу экрана (`position: fixed; bottom: 0`), с blur-фоном, кнопки "Назад" (secondary) и основное действие (синяя, `--blue`).
- **Тосты**: всплывающие уведомления снизу экрана над нижней панелью, тёмный фон, скругление.
- **Сводка сверки данных**: список с цветной точкой-индикатором (зелёная/оранжевая/красная) слева от текста.

## Правило для будущих итераций

При добавлении новой функциональности (новые поля, новые проверки, новые шаги):
1. Использовать те же CSS-переменные (`--radius-*`, `--color-*`, `--shadow`, `--space` через существующие значения).
2. Не вводить новые цвета вне палитры выше без явного запроса пользователя.
3. Сохранять структуру "card + section-title" для новых блоков.
4. Сохранять мобильный форм-фактор с максимальной шириной 600px.
5. Перед любой переработкой внешнего вида — уточнить у пользователя, так как этот стиль отмечен как понравившийся и финальный.
